# Vee Technologies Chennai -- Interview Preparation

## 1. Angular Lazy Loading

### A. Lazy loading a module

Use `loadChildren` when the feature is organized as an Angular module.

``` ts
const routes: Routes = [
  {
    path: 'products',
    loadChildren: () =>
      import('./products/products.module')
        .then(m => m.ProductsModule)
  }
];
```

**Interview answer:**

> Lazy loading means I don't load every feature when the application
> starts. I load a feature only when the user navigates to that route.
> This reduces the initial bundle size and improves application startup
> performance.

### B. Lazy loading a standalone component

For standalone components, use `loadComponent`.

``` ts
const routes: Routes = [
  {
    path: 'profile',
    loadComponent: () =>
      import('./profile/profile.component')
        .then(c => c.ProfileComponent)
  }
];
```

**Difference:**

  `loadChildren`                `loadComponent`
  ----------------------------- -----------------------------------
  Lazy-loads routes/module      Lazy-loads a standalone component
  Common with feature modules   Common with standalone Angular
  Returns module/routes         Returns component

# 2. Angular Service -- Get Data From Backend

A common interview question is:

> How do you write a service and subscribe to the API response in the
> component?

## Service

``` ts
import { Injectable } from '@angular/core';
import { HttpClient } from '@angular/common/http';
import { Observable } from 'rxjs';

export interface User {
  id: number;
  name: string;
  email: string;
}

@Injectable({
  providedIn: 'root'
})
export class UserService {

  private apiUrl = 'http://localhost:8080/api/users';

  constructor(private http: HttpClient) {}

  getUsers(): Observable<User[]> {
    return this.http.get<User[]>(this.apiUrl);
  }
}
```

## Component

``` ts
import { Component, OnInit } from '@angular/core';
import { UserService, User } from './user.service';

@Component({
  selector: 'app-user',
  templateUrl: './user.component.html'
})
export class UserComponent implements OnInit {

  users: User[] = [];

  constructor(private userService: UserService) {}

  ngOnInit(): void {
    this.userService.getUsers().subscribe({
      next: (data) => {
        this.users = data;
        console.log(data);
      },
      error: (error) => {
        console.error(error);
      },
      complete: () => {
        console.log('API completed');
      }
    });
  }
}
```

### Interview explanation

> I keep the HTTP call inside the service rather than directly inside
> the component. The service returns an Observable. In the component, I
> subscribe to it and handle `next`, `error`, and `complete`. For larger
> applications, I can also use the async pipe to avoid manually managing
> subscriptions.

### Better Angular approach -- async pipe

``` ts
users$ = this.userService.getUsers();
```

Template:

``` html
<div *ngFor="let user of users$ | async">
  {{ user.name }}
</div>
```

# 3. How Do You Handle Errors Globally in Angular?

For common HTTP errors, I use an **HTTP interceptor**.

``` ts
@Injectable()
export class ErrorInterceptor implements HttpInterceptor {

  intercept(
    req: HttpRequest<any>,
    next: HttpHandler
  ): Observable<HttpEvent<any>> {

    return next.handle(req).pipe(
      catchError((error: HttpErrorResponse) => {

        if (error.status === 401) {
          // logout / redirect to login
        } else if (error.status === 403) {
          // access denied
        } else if (error.status >= 500) {
          // server error
        }

        return throwError(() => error);
      })
    );
  }
}
```

### Interview answer

> I handle common HTTP errors globally using an HTTP interceptor. It
> intercepts every outgoing API response, so I can handle 401, 403, 404
> and 5xx errors consistently. For UI-specific errors, I handle them at
> the component or service level.

### Important distinction

-   **Interceptor** → global HTTP/API errors
-   **Component/service `catchError`** → API-specific handling
-   **Global ErrorHandler** → unexpected application/runtime errors

# 4. Backend -- How Do You Build the API?

For a Java backend, I commonly use:

``` text
Angular
   |
   | HTTP / REST API
   v
Controller
   |
   v
Service
   |
   v

   |
   v
```

## Controller

``` java
@RestController
@RequestMapping("/api/users")
public class UserController {

    private final UserService userService;

    public UserController(UserService userService) {
        this.userService = userService;
    }
```

## Service

``` java
@Service
public class UserService {

    private final UserRepository userRepository;

    public UserService(UserRepository userRepository) {
        this.userRepository = userRepository;
    }

    public List<User> getUsers() {
        return userRepository.findAll();
    }
```

``` java
@Repository

        extends JpaRepository<User, Long> {
}
```

### Interview answer

> In the backend, I normally follow a layered architecture. The
> controller handles HTTP requests, the service contains business logic,
> and the repository handles database operations. The controller returns
> the response to Angular as JSON.

# 5. Stack / Number Problem

### Input

The elements are given from **top to bottom**:

``` text
-3 14 18 -5 30
```

### Expected output

``` text
30 18 14 -3 -5
```

This output is the numbers sorted in **descending order**, with the
larger values first.

## Simple Java approach

``` java
int[] arr = {-3, 14, 18, -5, 30};

Arrays.sort(arr);

for (int i = arr.length - 1; i >= 0; i--) {
    System.out.print(arr[i] + " ");
}
```

### Output

``` text
30 18 14 -3 -5
```

## If they specifically ask to use a Stack

``` java
Stack<Integer> stack = new Stack<>();

stack.push(-3);
stack.push(14);
stack.push(18);
stack.push(-5);
stack.push(30);

List<Integer> list = new ArrayList<>(stack);

list.sort(Collections.reverseOrder());

for (int n : list) {
    System.out.print(n + " ");
}
```

### Stream API version

``` java
List<Integer> result = stack.stream()
        .sorted(Comparator.reverseOrder())
        .toList();

System.out.println(result);
```

Output:

``` text
[30, 18, 14, -3, -5]
```

### Interview point

If the interviewer asks **"Can you do it without sorting?"**, explain
the required ordering and implement the comparison manually. Don't
immediately assume that the word "stack" means the answer must use only
`push()` and `pop()`.

# 6. Merge Two Sorted Arrays

### Input

``` java
arr1 = {1, 3, 4, 5}
arr2 = {2, 4, 6, 8}
```

### Output

``` text
{1, 2, 3, 4, 4, 5, 6, 8}
```

Both input arrays are already sorted.

## A. Normal Java -- Two Pointer Approach

This is the best approach to explain in an interview because it is
**O(n + m)**.

``` java
public static int[] merge(int[] arr1, int[] arr2) {

    int[] result = new int[arr1.length + arr2.length];

    int i = 0;
    int j = 0;
    int k = 0;

    while (i < arr1.length && j < arr2.length) {

        if (arr1[i] <= arr2[j]) {
            result[k++] = arr1[i++];
        } else {
            result[k++] = arr2[j++];
        }
    }

    while (i < arr1.length) {
        result[k++] = arr1[i++];
    }

    while (j < arr2.length) {
        result[k++] = arr2[j++];
    }

    return result;
}
```

### Test

``` java
int[] arr1 = {1, 3, 4, 5};
int[] arr2 = {2, 4, 6, 8};

int[] result = merge(arr1, arr2);

System.out.println(Arrays.toString(result));
```

### Output

``` text
[1, 2, 3, 4, 4, 5, 6, 8]
```

### How to explain it

> I use two pointers, one for each sorted array. I compare the current
> elements and put the smaller one into the result. After one array is
> exhausted, I copy the remaining elements from the other array. The
> time complexity is O(n + m).

# 7. Merge Using Java Streams

A simple Stream API solution is:

``` java
int[] arr1 = {1, 3, 4, 5};
int[] arr2 = {2, 4, 6, 8};

int[] result = IntStream.concat(
        Arrays.stream(arr1),
        Arrays.stream(arr2)
    )
    .sorted()
    .toArray();

System.out.println(Arrays.toString(result));
```

Output:

``` text
[1, 2, 3, 4, 4, 5, 6, 8]
```

### Stream interview explanation

> I can concatenate both arrays using `IntStream.concat()`, sort the
> combined stream, and convert it back to an array. This is concise, but
> because the original arrays are already sorted, the two-pointer
> solution is more efficient.

### Complexity

  Approach                            Time           Extra Space
  -------------------- ------------------- ---------------------
  Two pointers                    O(n + m)   O(n + m) for result
  Concatenate + sort     O((n+m) log(n+m))              O(n + m)

# 8. How Do You Connect Backend Code to Frontend?

The connection happens through **REST APIs over HTTP/HTTPS**.

``` text
Angular Frontend
       |
       | GET /api/users
       v
Spring Boot Controller
       |
       v
Service
       |
       v
Repository
       |
       v
Database
```

## Backend endpoint

``` java
@GetMapping("/users")
public List<User> getUsers() {
    return userService.getUsers();
}
```

Suppose the backend runs at:

``` text
http://localhost:8080
```

The API becomes:

``` text
GET http://localhost:8080/api/users
```

## Angular service

``` ts
getUsers(): Observable<User[]> {
  return this.http.get<User[]>(
    'http://localhost:8080/api/users'
  );
}
```

### What happens?

1.  Angular calls the service.
2.  `HttpClient` sends an HTTP request.
3.  Spring Boot receives it in the controller.
4.  Controller calls the service.
5.  Service calls repository/database.
6.  Backend returns JSON.
7.  Angular receives the response and displays it.

# 9. CORS -- Important Backend/Frontend Question

If Angular runs on:

``` text
http://localhost:4200
```

and Spring Boot runs on:

``` text
http://localhost:8080
```

they are different origins.

Spring Boot can allow the Angular origin.

``` java
@Configuration
public class CorsConfig {

    @Bean
    public WebMvcConfigurer corsConfigurer() {
        return new WebMvcConfigurer() {

            @Override
            public void addCorsMappings(
                    CorsRegistry registry) {

                registry.addMapping("/**")
                        .allowedOrigins("http://localhost:4200")
                        .allowedMethods(
                            "GET", "POST",
                            "PUT", "DELETE"
                        )
                        .allowedHeaders("*");
            }
        };
    }
}
```

### Interview answer

> When frontend and backend are hosted on different origins, the browser
> can block the request because of CORS. I configure CORS on the backend
> or use a reverse proxy/API gateway depending on the deployment
> architecture. I avoid allowing all origins in production unless there
> is a specific requirement.

# 10. What Structure / Architecture Are You Using?

For a Java Spring Boot + Angular application, explain it as:

``` text
              Angular
                 |
            HTTP / REST
                 |
        +--------v---------+
        |    Controller    |
        +--------+---------+
                 |
        +--------v---------+
        |     Service      |
        | Business Logic   |
        +--------+---------+
                 |
        +--------v---------+
        |    Repository    |
        +--------+---------+
                 |
        +--------v---------+
        |    Database      |
        +------------------+
```

## Backend package structure

``` text
src/main/java/com/example/app
│
├── controller
│   └── UserController.java
│
├── service
│   ├── UserService.java
│   └── UserServiceImpl.java
│
├── repository
│   └── UserRepository.java
│
├── entity
│   └── User.java
│
├── dto
│   └── UserDto.java
│
├── exception
│   ├── GlobalExceptionHandler.java
│   └── UserNotFoundException.java
│
├── config
│   ├── SecurityConfig.java
│   └── CorsConfig.java
│
└── Application.java
```

### How to say it

> I generally use a layered architecture in Spring Boot. I separate
> controller, service, repository, entity or DTO, exception and
> configuration packages. The controller handles requests, the service
> contains business logic, the repository handles persistence, and DTOs
> help avoid exposing entities directly through APIs.

# 13. Quick Revision -- Vee Technologies

### Angular

-   Lazy loading → `loadChildren`
-   Standalone lazy loading → `loadComponent`
-   API call → Angular `HttpClient`
-   API response → `Observable`
-   Subscription → `subscribe()`
-   Global HTTP error → `HttpInterceptor`
-   Runtime application error → `ErrorHandler`

### Spring Boot

-   API layer → `@RestController`
-   Business layer → `@Service`
-   Database layer → `@Repository`
-   Entity → `@Entity`
-   Request/response model → DTO
-   Global exception → `@ControllerAdvice`
-   Cross-origin requests → CORS configuration

### Java coding

-   Stack/output question → clarify the required ordering
-   Merge sorted arrays → two pointers
-   Stream merge → `IntStream.concat(...).sorted()`
-   Two-pointer complexity → **O(n + m)**

### One-line architecture answer

> I use a layered Spring Boot architecture with Controller → Service →
> Repository → Database, and Angular communicates with the backend
> through REST APIs using `HttpClient` and Observables.
