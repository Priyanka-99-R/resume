## ✅ Interview-day checklist

- [ ] Can deliver the 60-second intro smoothly without notes
- [ ] Can draw the architecture of **RoboGebra** and **EasyVisa** on a whiteboard
- [ ] Have **one strong "challenge I solved"** story ready per project (STAR format)
- [ ] Can explain RxJS `switchMap` vs `mergeMap` and the `takeUntil` unsubscribe pattern
- [ ] Can explain Spring Boot auto-configuration and `@SpringBootApplication`
- [ ] Can code FizzBuzz, palindrome, two-sum, and reverse-a-string from memory
- [ ] Can answer the **output-based Java programs** in [23](./23-java-output-tricky-questions.md) — especially `methodTest(null)` and the `throws IOException` override
- [ ] Can say the one-liner: *"Overloading = compiler decides by the reference type. Overriding = JVM decides by the object type."*
- [ ] Can explain **`setValue` vs `patchValue`**, **`value` vs `getRawValue()`**, and write a **cross-field + async validator** ([25](./25-angular-binding-forms.md))
- [ ] Can implement **`ControlValueAccessor`** and desugar **`[(ngModel)]`** on a whiteboard
- [ ] Can answer **"Have you used ORM?"** honestly — *RoboGebra is MongoDB, so it's an **ODM**, not an ORM* — and still explain JPA concepts (persistence context, N+1, `@Transactional`) confidently ([24](./24-orm-jpa-hibernate.md))
- [ ] Have 2–3 thoughtful questions ready to ask the interviewer
- [ ] Be honest about **AWS & Microservices = basic/working knowledge** — don't oversell
