## Java

### 1. Find the frequency of occurrence of characters

**Question:**  
Given a string, find how many times each character occurs.

**Example:**
```text
Input:  "programming"

Output:
p:1
r:2
o:1
g:2
a:1
m:2
i:1
n:1
```

### Answer – Using Stream API

```java
import java.util.*;
import java.util.function.Function;
import java.util.stream.Collectors;

public class CharacterFrequency {
    public static void main(String[] args) {

        String str = "programming";

        Map<Character, Long> frequency = str.chars()
                .mapToObj(c -> (char) c)
                .collect(Collectors.groupingBy(
                        Function.identity(),
                        LinkedHashMap::new,
                        Collectors.counting()
                ));

        frequency.forEach((ch, count) ->
                System.out.println(ch + ":" + count));
    }
}
```

**How to explain in interview:**

> "I convert the string into a stream of characters, then use `groupingBy` with `Function.identity()` and `counting()` to count each character. I use `LinkedHashMap` if I want to preserve the original order."

**Important:**  
If the interviewer asks for **word frequency**, the same approach can be applied after splitting the sentence into words.

## 2. Reverse a String Using Stream API Without Inbuilt Reverse Methods

**Question:**  
Reverse a string using Java Stream API without using `StringBuilder.reverse()` or other reverse methods.

### Answer

```java
import java.util.stream.Collectors;
import java.util.stream.IntStream;

public class ReverseString {
    public static void main(String[] args) {

        String str = "hello";

        String reversed = IntStream.range(0, str.length())
                .mapToObj(i -> str.charAt(str.length() - 1 - i))
                .map(String::valueOf)
                .collect(Collectors.joining());

        System.out.println(reversed);
    }
}
```

**Output:**
```text
olleh
```

**Interview explanation:**

> "I create an integer stream from 0 to the string length. For every index, I access the character from the opposite end using `length - 1 - i`, and finally join the characters into a string."

### Alternative – Stream over Character Array

```java
String str = "hello";

String reversed = IntStream.range(0, str.length())
        .mapToObj(i -> str.charAt(str.length() - 1 - i))
        .collect(
                StringBuilder::new,
                StringBuilder::append,
                StringBuilder::append
        )
        .toString();

System.out.println(reversed);
```

For an interview, the **first solution is simpler to explain**.

## 3. Find the Largest Value in a String

This question can mean different things. A common interview interpretation is:

**Question:**  
Given a string containing numbers, find the largest number.

**Example:**
```text
Input: "10 25 7 99 42"

Output: 99
```

### Answer

```java
import java.util.Arrays;

public class LargestNumber {
    public static void main(String[] args) {

        String str = "10 25 7 99 42";

        int largest = Arrays.stream(str.split(" "))
                .mapToInt(Integer::parseInt)
                .max()
                .orElseThrow();

        System.out.println(largest);
    }
}
```

**Interview explanation:**

> "I split the string into individual values, convert them to integers using `mapToInt`, and use `max()` to find the largest value."

### If interviewer means largest character

```java
String str = "programming";

char largest = str.chars()
        .mapToObj(c -> (char) c)
        .max(Character::compareTo)
        .orElseThrow();

System.out.println(largest);
```

# SQL

## 4. Average Salary Query

**Question:**  
Find the average salary from an employee table.

Assume:

```text
employee
----------------
id
name
salary
department
```

### Basic Query

```sql
SELECT AVG(salary) AS average_salary
FROM employee;
```

**Interview explanation:**

> "`AVG()` is an aggregate function that calculates the average of the salary column."

### Average Salary by Department

```sql
SELECT department, AVG(salary) AS average_salary
FROM employee
GROUP BY department;
```

### Average Salary Greater Than 50,000

```sql
SELECT AVG(salary) AS average_salary
FROM employee
WHERE salary > 50000;
```

### Average Salary with Two Decimal Places

For databases that support `ROUND()`:

```sql
SELECT ROUND(AVG(salary), 2) AS average_salary
FROM employee;
```

**Important interview point:**

- `WHERE` filters rows **before** grouping/aggregation.
- `HAVING` filters groups **after** `GROUP BY`.

Example:

```sql
SELECT department, AVG(salary) AS average_salary
FROM employee
GROUP BY department
HAVING AVG(salary) > 50000;
```

# Spring Boot

## 5. WebClient Integration – Calling an External API

**Question:**  
How do you integrate an external API in Java Spring Boot?

### Interview Answer

> "In Spring Boot, I can use `WebClient` to call an external REST API. I create a WebClient bean, call the external endpoint using HTTP methods like GET or POST, map the response to a DTO, and handle errors and timeouts. I keep the external API call inside a service layer rather than directly inside the controller."

### Step 1 – WebClient Configuration

```java
import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;
import org.springframework.web.reactive.function.client.WebClient;

@Configuration
public class WebClientConfig {

    @Bean
    public WebClient webClient(WebClient.Builder builder) {
        return builder
                .baseUrl("https://api.example.com")
                .build();
    }
}
```

### Step 2 – Response DTO

```java
public class UserResponse {

    private Long id;
    private String name;
    private String email;

    public Long getId() {
        return id;
    }

    public void setId(Long id) {
        this.id = id;
    }

    public String getName() {
        return name;
    }

    public void setName(String name) {
        this.name = name;
    }

    public String getEmail() {
        return email;
    }

    public void setEmail(String email) {
        this.email = email;
    }
}
```

### Step 3 – Service

```java
import org.springframework.stereotype.Service;
import org.springframework.web.reactive.function.client.WebClient;

@Service
public class ExternalApiService {

    private final WebClient webClient;

    public ExternalApiService(WebClient webClient) {
        this.webClient = webClient;
    }

    public UserResponse getUser(Long id) {

        return webClient.get()
                .uri("/users/{id}", id)
                .retrieve()
                .bodyToMono(UserResponse.class)
                .block();
    }
}
```

### Step 4 – Controller

```java
import org.springframework.web.bind.annotation.*;

@RestController
@RequestMapping("/api")
public class UserController {

    private final ExternalApiService externalApiService;

    public UserController(ExternalApiService externalApiService) {
        this.externalApiService = externalApiService;
    }

    @GetMapping("/users/{id}")
    public UserResponse getUser(@PathVariable Long id) {
        return externalApiService.getUser(id);
    }
}
```

### How the flow works

```text
Angular
   |
   v
Spring Boot Controller
   |
   v
Service
   |
   v
WebClient
   |
   v
External REST API
   |
   v
Response DTO
   |
   v
Angular
```

### Error Handling

A simple example:

```java
public UserResponse getUser(Long id) {

    return webClient.get()
            .uri("/users/{id}", id)
            .retrieve()
            .onStatus(
                    status -> status.is4xxClientError(),
                    response -> response.createException()
            )
            .bodyToMono(UserResponse.class)
            .block();
}
```

### Important interview question: Why WebClient?

> "WebClient is Spring's modern HTTP client. It supports both synchronous-style usage and reactive, non-blocking communication. For a traditional Spring MVC application, I can still use it, but I should be careful about calling `.block()` because it makes that particular call synchronous."

### Other possible answer

Spring Boot applications can also use `RestClient` for synchronous HTTP calls. If the interviewer specifically asks for **WebClient**, answer with WebClient as above.

# 6. File Download – Data Types and Complete Spring Boot Code

**Question:**  
How do you implement file download in Spring Boot? Which data type do you use?

### Interview Answer

> "For a file download, the response body can be represented as `byte[]` for smaller files. I return it using `ResponseEntity<byte[]>` along with the appropriate `Content-Type` and `Content-Disposition` headers. For large files, I would prefer streaming instead of loading the entire file into memory."

## Simple `byte[]` Example

### Controller

```java
import org.springframework.core.io.Resource;
import org.springframework.http.*;
import org.springframework.web.bind.annotation.*;

import java.io.IOException;
import java.nio.file.Files;
import java.nio.file.Path;

@RestController
@RequestMapping("/files")
public class FileController {

    @GetMapping("/download")
    public ResponseEntity<byte[]> downloadFile() throws IOException {

        Path path = Path.of("C:/files/sample.pdf");

        byte[] data = Files.readAllBytes(path);

        HttpHeaders headers = new HttpHeaders();

        headers.setContentType(MediaType.APPLICATION_PDF);
        headers.setContentDisposition(
                ContentDisposition.attachment()
                        .filename("sample.pdf")
                        .build()
        );

        return new ResponseEntity<>(
                data,
                headers,
                HttpStatus.OK
        );
    }
}
```

### What data types are involved?

```text
File on disk
     |
     v
Path
     |
     v
byte[]
     |
     v
ResponseEntity<byte[]>
     |
     v
HTTP response
```

**Key point:**

```java
byte[] data
```

is useful for smaller files because the complete file is loaded into memory.

---

## Better Approach for Large Files – Resource

For large files, use Spring's `Resource` abstraction.

```java
import org.springframework.core.io.FileSystemResource;
import org.springframework.core.io.Resource;
import org.springframework.http.*;
import org.springframework.web.bind.annotation.*;

@RestController
@RequestMapping("/files")
public class FileController {

    @GetMapping("/large-download")
    public ResponseEntity<Resource> downloadLargeFile() {

        Resource resource =
                new FileSystemResource("C:/files/large-file.pdf");

        HttpHeaders headers = new HttpHeaders();

        headers.setContentType(MediaType.APPLICATION_PDF);
        headers.setContentDisposition(
                ContentDisposition.attachment()
                        .filename("large-file.pdf")
                        .build()
        );

        return ResponseEntity.ok()
                .headers(headers)
                .body(resource);
    }
}
```

### Interview follow-up: byte[] vs Resource

| `byte[]` | `Resource` |
|---|---|
| Entire file loaded into memory | Better suited to file/resource handling |
| Simple | Better for larger files |
| Suitable for smaller files | Prefer for large downloads |
| Can increase memory usage | Supports resource-based access |

**Speakable answer:**

> "For a small file, I can use `byte[]` with `ResponseEntity<byte[]>`. For a large file, I prefer `Resource` or streaming so that I don't load the entire file into memory."

# Angular

## 1. Lazy Loading

**Question:**  
What is lazy loading in Angular?

### Answer

> "Lazy loading means loading a feature only when it is required instead of loading the complete application at startup. It reduces the initial JavaScript bundle and improves initial application load time."

### Example – Lazy Loaded Route

```typescript
import { Routes } from '@angular/router';

export const routes: Routes = [
  {
    path: 'admin',
    loadChildren: () =>
      import('./admin/admin.routes')
        .then(m => m.ADMIN_ROUTES)
  }
];
```

The admin code is loaded when the user navigates to:

```text
/admin
```

### Interview explanation

```text
Application starts
      |
      v
Load only required code
      |
      v
User opens /admin
      |
      v
Angular downloads admin chunk
      |
      v
Admin page loads
```

# 2. `loadComponent` vs `loadChildren`

This is an important Angular interview question.

## `loadComponent`

Used when you want to lazy-load **one standalone component**.

```typescript
{
  path: 'profile',
  loadComponent: () =>
    import('./profile/profile.component')
      .then(m => m.ProfileComponent)
}
```

The component must be standalone.

```typescript
@Component({
  selector: 'app-profile',
  standalone: true,
  templateUrl: './profile.component.html'
})
export class ProfileComponent {
}
```

## `loadChildren`

Used when you want to lazy-load a **set of routes/feature area**.

```typescript
{
  path: 'admin',
  loadChildren: () =>
    import('./admin/admin.routes')
      .then(m => m.ADMIN_ROUTES)
}
```

### Easy way to remember

```text
loadComponent
       ↓
One standalone component

loadChildren
       ↓
Multiple routes / feature area
```

### Interview answer

> "`loadComponent` is useful for lazy-loading a single standalone component. `loadChildren` is useful for lazy-loading a group of child routes or a feature area."

# 3. How Do You Handle a Large Amount of Data in Angular?

**Question:**  
If the API returns a very large amount of data, how do you handle it?

### Interview Answer

> "I would avoid loading all the data into the browser at once. I would implement server-side pagination, filtering and sorting. On the Angular side, I can use pagination or virtual scrolling, debounce search requests, use `trackBy` where appropriate, and avoid unnecessary change detection. For very large lists, I can use Angular CDK virtual scrolling."

### Recommended approach

```text
Angular
   |
   | page=1&size=20
   v
Spring Boot
   |
   v
Database
   |
   | return only 20 records
   v
Angular
```

### Example API

```text
GET /api/employees?page=0&size=20
```

### Angular Example

```typescript
getEmployees(page: number, size: number) {
  return this.http.get<Employee[]>(
    `/api/employees?page=${page}&size=${size}`
  );
}
```

### Additional techniques

1. **Server-side pagination**
2. **Server-side filtering**
3. **Server-side sorting**
4. **Virtual scrolling**
5. **Lazy loading**
6. **Debounce search**
7. **`trackBy` / `track` in lists**
8. **`OnPush` change detection where appropriate**
9. **Avoid unnecessary API calls**
10. **Caching when appropriate**

### Speakable answer

> "For large data, my first choice is server-side pagination because sending thousands of records to the browser is inefficient. I return only the required page from the backend. For large visible lists, I can additionally use virtual scrolling."

# 4. Component Communication

**Question:**  
How do Angular components communicate with each other?

There are several approaches depending on the relationship between the components.

## 1. Parent → Child: `@Input`

Parent:

```html
<app-child [userName]="name"></app-child>
```

Child:

```typescript
@Input() userName = '';
```

### Explanation

> "I use `@Input` when the parent needs to pass data to the child."

---

## 2. Child → Parent: `@Output`

Child:

```typescript
@Output() message =
  new EventEmitter<string>();

sendMessage() {
  this.message.emit('Hello Parent');
}
```

Parent:

```html
<app-child
  (message)="receiveMessage($event)">
</app-child>
```

```typescript
receiveMessage(message: string) {
  console.log(message);
}
```

### Explanation

> "I use `@Output` with `EventEmitter` when the child needs to send an event or data to the parent."

---

## 3. Sibling Components

For sibling components, a common approach is a shared service.

```typescript
@Injectable({
  providedIn: 'root'
})
export class MessageService {

  private messageSubject =
    new Subject<string>();

  message$ = this.messageSubject.asObservable();

  sendMessage(message: string) {
    this.messageSubject.next(message);
  }
}
```

Component A:

```typescript
this.messageService.sendMessage('Hello');
```

Component B:

```typescript
this.messageService.message$
    .subscribe(message => {
      console.log(message);
    });
```

### Explanation

> "For sibling components, I can use a shared service with RxJS Subject or BehaviorSubject. For application-wide state, I can also use a state-management solution when the application requires it."

# 5. What is a Standalone Component?

**Question:**  
What is a standalone component in Angular?

### Answer

> "A standalone component is a component that doesn't need to be declared inside an NgModule. It can directly import the components, directives and pipes that it uses."

### Example

```typescript
import { Component } from '@angular/core';
import { CommonModule } from '@angular/common';

@Component({
  selector: 'app-user',
  standalone: true,
  imports: [CommonModule],
  template: `
    <h2>{{ name }}</h2>

    <p *ngIf="isActive">
      User is active
    </p>
  `
})
export class UserComponent {

  name = 'Priyanka';
  isActive = true;
}
```

### Traditional NgModule approach

Previously, a component was commonly declared inside an NgModule:

```typescript
@NgModule({
  declarations: [
    UserComponent
  ]
})
export class UserModule {
}
```

With a standalone component:

```typescript
@Component({
  standalone: true
})
export class UserComponent {
}
```

No component declaration in an NgModule is required.

### Why use standalone components?

- Less NgModule boilerplate
- Direct dependency imports
- Easier lazy loading
- Good fit for modern Angular applications
- Makes component dependencies more explicit

### Standalone + Lazy Loading

This is a common interview combination:

```typescript
{
  path: 'user',
  loadComponent: () =>
    import('./user.component')
      .then(m => m.UserComponent)
}
```

Here:

```text
Standalone Component
        +
  loadComponent
        =
Lazy-loaded standalone component
```
